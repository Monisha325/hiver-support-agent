# PrepAI Project Instructions

You are an expert full-stack engineer, UI/UX designer, and AI product architect.

Build a production-ready SaaS application called PrepAI.

## Product Overview
PrepAI is an AI-powered interview preparation platform that helps users:
- Generate role-specific interview questions
- Practice mock interviews
- Receive AI-based answer evaluation
- Upload resumes and get ATS analysis
- Track progress through analytics
- Get personalized study recommendations

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Prisma ORM
- PostgreSQL
- Clerk Authentication
- OpenAI API
- UploadThing
- Recharts

## Design Requirements
- Premium SaaS design inspired by Vercel, Linear, and Notion
- Responsive across desktop, tablet, and mobile
- Dark and light mode
- Smooth animations
- Accessible components
- Clean typography and strong visual hierarchy

## Branding
