Data drift is when the input data distribution changes. Concept drift is when the relationship between the input and output changes.
Detect data drift by comparing the production data distribution with the training data.
Detect concept drift by monitoring accuracy, precision, and recall drop over time.
If performance metrics drop over time while the input data looks similar, then it is likely to be concept drift.
